Problem 1: Fibonacci Variants

F(n) = F(n-1) + F(n-2) + F(n-3)
Base cases: F(0) = 1, F(1) = 1, F(2) = 1

I used a simple loop:

def modified_fib(n):
    if n <= 2: return 1
    a, b, c = 1, 1, 1
    for i in range(3, n + 1):
        a, b, c = b, c, a + b + c
    return c

Time complexity is O(n) since we loop from 3 to n once.

Problem 2: Coin Change

Let dp[i] be the fewest coins needed to make amount i.
Transition: dp[i] = min over all coins c of (dp[i - c] + 1), where c <= i.
Base case: dp[0] = 0.

def min_coins(amount):
    coins = [1, 5, 10, 25]
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for c in coins:
            if c <= i and dp[i - c] + 1 < dp[i]:
                dp[i] = dp[i - c] + 1
    if dp[amount] == float('inf'):
        return -1
    return dp[amount]

The greedy approach (always picking the largest coin) also works for US denominations because they form a canonical coin system. However, the DP approach is more general and works for any set of denominations.
