Problem 1: Fibonacci Variants

Recurrence: F(n) = F(n-1) + F(n-2) + F(n-3)
Base cases: F(0) = 0, F(1) = 0, F(2) = 1

I wrote a recursive function with memoization using a dictionary:

memo = {}
def fib3(n):
    if n in memo: return memo[n]
    if n == 0 or n == 1: return 0
    if n == 2: return 1
    result = fib3(n-1) + fib3(n-2) + fib3(n-3)
    memo[n] = result
    return result

This avoids recomputation by storing previously computed values.

Problem 2: Coin Change

dp[0] = 0. For each amount from 1 to n, try all four coins and take the minimum.

def coin_change(n):
    coins = [1, 5, 10, 25]
    dp = [float('inf')] * (n + 1)
    dp[0] = 0
    for i in range(1, n + 1):
        for c in coins:
            if c <= i:
                dp[i] = min(dp[i], dp[i - c] + 1)
    return dp[n]

The code works correctly. I tested it with n=30 and got 2 (a quarter + a nickel).

I did not handle the case where the amount is impossible since with a 1-cent coin any positive amount is reachable.
